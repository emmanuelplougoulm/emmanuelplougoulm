# Hi, I'm Emmanuel 👋

**Testing like a developer. Seeing like a designer.**

SDET based in Paris. I build end-to-end test automation with Playwright and TypeScript,
and I care about what users actually see: visual regression, accessibility, UI consistency.

Tests are software too: I give test code the same care as the product it tests,
and I measure what each architecture choice actually costs.

- 🧪 **Now**: QA engineer: manual testing and Playwright automation, owning the front-end scope
- 💻 **Before**: 5+ years as a fullstack JS/TS developer
- 🎨 **Before that**: graphic designer at Fabrica (Benetton) and Baillat Cardell & fils (Montréal), then freelance
- 📜 ISTQB CTFL certified, working towards CTAL-TAE
